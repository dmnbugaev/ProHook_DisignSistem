## 4. Широкая чистка приставок категорий в названиях (img_2 + решение владельца)
Приставка зашита в значениях атрибута «Название для сайта» в МойСклад — правим данные через API (только Node fetch, curl МойСклад режет 415):
- Новый скрипт `scripts/mass-rename/strip-category-prefix.mjs` (на базе `lib.mjs` + паттерна `write-back.mjs`):
  - читает актуальные товары с атрибутом из API МойСклад (backup от 07.10 не источник истины);
  - строит словарь форм имён папок (корень и предки: «Снеки»→«Снек», «Одноразовые ЭС»→«Одноразовая ЭС», «Предзаправленные картриджи»→«Предзаправленный картридж» и т.п.);
  - если «Название для сайта» начинается с такой формы И этих слов нет в исходном имени МойСклад — отрезает приставку (затронет ~100–150 позиций: Снек, Одноразовая, Предзаправленный, Жевательный табак у части SKU и др.); описательные слова, не являющиеся категорией («Батончик», «Газированный», «Энергетический»…), не трогаем;
  - сначала `--dry-run`: полный список «до → после», просматриваю; бэкап текущих значений в `out/strip-backup-*.json`; затем PUT в атрибут (id 5c57847f…).
- После записи: `npm run catalog:sync` + jq-контроль снимка (нет «Снек …» и других приставок).
