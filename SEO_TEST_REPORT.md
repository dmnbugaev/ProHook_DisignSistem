## 6. Ограничения

1. Лабораторные метрики (LCP/CLS) сняты на localhost (TTFB занижен) —
   годятся для до/после; полевые CWV — через Яндекс Вебмастер/Метрику
   после публикации.
2. INP не измеряется лабораторно (нет детерминированного метода);
   косвенный контроль — производительность гидрации в e2e и отсутствие
   pageerror в тестах адаптивности.
3. Проверка реальной доставки данных в счётчик 113582832 возможна только
   после публикации (интерфейс Метрики); e2e проверяет очередь вызовов
   официального загрузчика до сети — этого достаточно для контракта
   интеграции.
4. Флаки полного прогона (8) — средовые (dev-сервер под параллельной
   нагрузкой), ретраи в конфиге; при изоляции все спеки стабильны.
