# PROHOOK — каталог товаров с МойСклад

Локальный проект на Nuxt 4, Vue 3 и TypeScript. Категории, товары, фотографии, цены и остатки загружаются сервером из МойСклад. Клиент не получает ключ API.

## Запуск

Node.js 22+; проверено на Node.js 24.21.0.

```sh
npm ci
cp .env.example .env
# Укажите NUXT_MOYSKLAD_TOKEN в .env
npm run catalog:sync
npm run dev
```

Открыть http://127.0.0.1:3000. Сервер слушает localhost. Публикация не настроена; страницы имеют `noindex, nofollow`.

```sh
npm run build
npm run preview
```

Production: `node .output/server/index.mjs`, Nitro node-server. На сервере требуется `NUXT_MOYSKLAD_TOKEN`; `.env` и `.cache` не добавляются в Git. При первом запуске без снимка каталог загружается из МойСклад, а остатки догружаются в фоне. Для предсказуемого первого открытия заранее выполните `npm run catalog:sync`.

## Страницы

| Адрес | Содержание |
| --- | --- |
| `/` | Главная: hero, категории, подборка, бренды, о проекте, магазины и контакты |
| `/catalog` | Фильтры, сортировка, количество результатов, карточки и пагинация |
| `/catalog/[category]` | Категория или подкатегория; родитель включает товары дочерних категорий |
| `/product/[slug]` | Галерея, характеристики, описание, цены и наличие по точкам, похожие товары |
| `/search?q=` | Поиск по названию, бренду и артикулу |
| `/about`, `/contacts`, `/stores` | Информационные страницы |
| `/information` | Об источнике каталога и хранении выбора магазина |
| `/design-system` | Исходная интерактивная витрина дизайн-системы |

AgeGate запрашивает 18+ при каждой загрузке документа. При переходах внутри Nuxt ответ сохраняется в памяти; после reload спрашивается снова. Без JavaScript интерфейс заблокирован и показано пояснение. После подтверждения предлагается выбрать город и магазин. Выбор точки хранится в cookie `prohook-store` на 30 дней и доступен при SSR.

По последним указаниям заказчика корзина, бронирование, заявки и избранное не входят в MVP.

  components/

    layout/                  Header и Footer сайта / витрины
    common/                  AgeGate, StorePicker, SearchForm
    product/                 одна ProductCard для всех выдач, галерея, цена
    catalog/                 фильтры, категории, toolbar, pagination, CatalogView
    sections/                композиции главной
    design-system/           сохранённая витрина
  composables/               useFetch, URL-фильтры, выбор точки, SEO
  pages/                     маршруты и композиция
shared/
  types/                     Product, Category, Brand, Store, CatalogQuery
  utils/                     разбор query и форматирование цены
server/
  api/                       HTTP-контракт Nuxt/Nitro
  repositories/catalog.ts    фильтрация, поиск и сортировка данных снимка

Pinia не требуется: глобального состояния мало, используются Nuxt `useState` и `useCookie`. Новые runtime-зависимости не добавлялись. Tailwind не вводился: исходный проект использует собственный CSS.

## Данные и API

- `GET /api/catalog/meta`: категории, бренды, города, магазины и материалы.
- `GET /api/products`: `{ items, total, page, pageCount }`.
- `GET /api/products/:slug`: `Product` или HTTP 404.

Query: `q`, `category`, `minPrice`, `maxPrice`, `available=1`, `storeId`, `sort`, `page`, `limit`. Внутренние подборки дополнительно используют `excludeId`.

Сортировки: `popular` (по дате последнего обновления для совместимости URL), `price-asc`, `price-desc`, `newest`. Фильтры и страницы синхронизированы с URL. Неизвестная категория/товар возвращает 404; некорректный диапазон цены или неизвестная точка — 400. Размер выдачи ограничен 24, страница приводится к существующему диапазону.

У `Product` есть массив `offers`: `storeId`, `price`, `currency`, `availability`. Денежные значения — целое количество копеек. Наличие — `available | low | unavailable | unknown`, без публикации количества. Фильтры цены в URL задаются в рублях. Для Саратова используется тип «Цена продажи», для Москвы — «Москва». Нулевая цена скрывает товар в соответствующем городе. Без выбранного магазина показывается минимальная положительная цена с подписью «от».

Данные поступают из МойСклад и сохраняются в `.cache/moysklad/catalog.json`. В каталог попадают неархивные обычные товары с положительной ценой хотя бы в одном городе. Если в МойСклад появится дополнительное поле «Показать на сайте», публикуются только отмеченные товары; сейчас такого поля нет. Модификации не включаются. Из 43 складов показываются торговые точки; служебные склады и точки «Вокзал», «Буровая», «Ильинская площадь» исключаются.

## Синхронизация

`npm run catalog:sync` загружает полный каталог и отчёт остатков перед запуском. Сервер читает снимок сразу и обновляет товары и остатки в фоне через пять минут. При временной ошибке МойСклад остаётся последний успешный снимок; если остатков ещё нет, выводится «Наличие уточняется».

Изображения открываются через серверный `/api/products/:id/images/:index`, поэтому ссылки скачивания и ключ МойСклад не попадают в браузер. Если изображения нет, интерфейс показывает существующую заглушку.

## UI Kit

Сохранены `UiButton`, `UiField`, `UiSelect`, `UiTabs`, `UiDialog`, `UiCard`. Выделены `UiContainer`, `UiIconButton`, `UiCheckbox`, `UiEmptyState`, `UiSkeleton`; добавлены `UiBadge`, `UiBreadcrumbs`.

Варианты кнопок остаются `primary / secondary / quiet`, размеры `normal / large`. `UiDialog` поддерживает модальную панель, `drawer` и обязательное подтверждение через `dismissible=false`. Диалоги удерживают фокус, обычные закрываются по Escape. `UiContainer` поддерживает семантический тег через `as`.

## Проверки

```sh
npm run lint
npm run format:check
npm run typecheck
npm run build
npm run test:unit
npm test
```

Форматирование: `npm run format`. Playwright запускает Chromium и WebKit; браузеры устанавливаются командой `npx playwright install chromium webkit`.

Проверка production-сборки после build:

```sh
PLAYWRIGHT_BASE_URL=http://127.0.0.1:4317 npm test
```

Тесты покрывают возраст, выбор точки, цены и наличие, cookie, фильтры, сортировки, back/forward, мобильный drawer, поиск, галерею, пустую выдачу, ошибки API, настоящие 404 и адаптивность. Старые проверки дизайн-системы сохранены. Результаты и скриншоты — в `docs/QA.md` и `docs/screenshots/`.

## Отложенные данные

Контакты сети приведены по официальному сообществу ВКонтакте; источники перечислены в `docs/CONTENT-SOURCES.md`. Юридические тексты заказчик пока не предоставил. Адреса магазинов берутся из МойСклад; если адрес не заполнен, он не показывается. При отсутствии часов конкретной точки указан общий режим сети с соответствующей подписью.
