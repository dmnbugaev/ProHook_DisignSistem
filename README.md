# Прохук — дизайн-система

Интерактивная витрина на Nuxt 4: айдентика, типографика, компоненты, служебные состояния и нейтральная геометрическая анимация. Это согласованный этап дизайн-системы, не товарный сайт.

## Запуск

Требуется Node.js 22+; проверено на Node.js 24.21.0 и npm 11.19.0.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000. Для просмотра с телефона в одной локальной сети: `npm run dev -- --host 0.0.0.0`, затем открыть показанный сетевой адрес. Публичная публикация не настроена.

```sh
npm run typecheck
npm run build
npm run preview
```

Для запуска готовой серверной сборки: `node .output/server/index.mjs`.

## Проверки

```sh
npx playwright install chromium webkit
npm test
```

Playwright самостоятельно запускает dev-сервер, если порт 3000 свободен; уже запущенный локальный сервер использует повторно. В CI требуется свободный порт. Сценарии работают в Chromium и WebKit: фокус и закрытие диалогов, мобильная навигация, клавиатура вкладок, ошибки полей, стабильность Header, reduced motion, обратимость scroll-анимации, размеры 320–1920 px, текст 200%, отсутствие JavaScript. При сбое trace сохраняется в `test-results/`.

Снимки интерфейса — в `docs/screenshots/`, результаты проверки — в `docs/QA.md`.

## Структура

- `app/app.vue` — единственная страница-витрина; примеры не отправляют данные.
- `app/components/` — независимые Vue-компоненты. Nuxt импортирует их автоматически.
- `app/assets/css/main.css` — семантические токены, общие стили и адаптивность.
- `public/brand/` — оптимизированные копии пользовательской айдентики.
- `public/fonts/Golos-Text-OFL.txt` — лицензия шрифта. Сам шрифт импортируется из npm-пакета, Vite включает локальные WOFF2 в сборку. Запросов к Google Fonts нет.
- `scripts/prepare-assets.mjs` — повторяемая оптимизация исходников через Sharp: `node scripts/prepare-assets.mjs`.

Оригинальные папки `логотп и изображения` и `референсы` не изменены. Изображения не генерировались: нейтральная композиция выполнена средствами CSS, а знак используется из предоставленных исходников.

## Интерфейсы компонентов

| Компонент | Параметры и поведение |
| --- | --- |
| `UiButton` | `variant`: primary / secondary / quiet; `size`: normal / large; `type`; `disabled`; `loading`. Содержимое — default slot, события передаются кнопке. Loading блокирует повторное действие без изменения ширины. |
| `UiField` | Строковый `v-model`; обязательный `label`; `hint`, `error`, `type`, `multiline`. Нативные атрибуты передаются input/textarea. Ошибка связывается через `aria-describedby`; ID создаётся через `useId`. |
| `UiSelect` | Строковый `v-model`, `label`, `options: { value, label }[]`; нативные атрибуты передаются select. |
| `UiTabs` | Строковый `v-model`, `label`, `tabs: { value, label }[]`. Панели — именованные slots по value. Модель должна совпадать с одной вкладкой, значения уникальны. Стрелки/Home/End меняют фокус и выбранную панель. |
| `UiDialog` | Булевый `v-model`, обязательный `title`, необязательный `menu`. Slot получает `close`. Нативный modal dialog блокирует фон, Tab/Shift+Tab зациклены, Escape закрывает, исходный фокус восстанавливается. |
| `UiCard` | `title`, `href`, `image`, `imageAlt`, необязательный `label`; описание — default slot. Ссылка в заголовке, без конфликтующих вложенных действий. |
| `SiteHeader` | Якорная навигация по разделам витрины, мобильное меню, стекло после 40 px прокрутки и возврат ниже 16 px. |
| `MotionStudy` | Три декоративные формы, естественный scroll, ручной статичный режим и системный reduced motion. |

Checkbox и radio используют нативные элементы с классом `choice`; служебные состояния демонстрируются в витрине. Серверных API, базы данных, аналитики, форм отправки и секретов нет.

## Материалы и ограничения

Векторный логотип и официальный брендбук не предоставлены. Рабочие правила, подтверждённые пользователем, зафиксированы в `DESIGN.md`. Полный логотип — `3.png`, знак — `2.png`; файл «основной логотип.png» рассматривается как декоративная форма и в интерфейсе не подменяет знак.

Статичные референсы изучены. У внешних сайтов ранее проверено текстовое содержание; точные анимации и мобильные композиции не подтверждены и не копируются. Витрина не использует их фотографии, тексты или логотипы.

Контакты, адреса, товарные фотографии и учётные данные МойСклад не нужны для этого согласованного этапа и не добавлялись.
