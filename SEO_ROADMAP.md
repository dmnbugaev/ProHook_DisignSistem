# SEO Roadmap — план на 30/60/90 дней и мониторинг

Стартовая точка: 2026-10-09 (см. SEO_AUDIT.md, SEO_IMPLEMENTATION_REPORT.md).

## Первые 30 дней (после мержа и деплоя)

**Владелец (без кода):**

1. Подтвердить права в Яндекс Вебмастере (файл
   `yandex_637e4d2139cdf333.html` уже на проду) — YANDEX_WEBMASTER_SETUP.md.
2. Добавить `https://прохук.рф/sitemap.xml` в Вебмастер.
3. Указать регион сайта: Саратов, Россия.
4. Создать цели Метрики 113582832 (JavaScript-события из таблицы
   YANDEX_METRIKA_SETUP.md §4); проверить настройки Вебвизора (запись
   содержимого полей — выкл) и фильтр localhost.
5. В «Информация о сайте» Вебмастера заполнить наименование/описание
   организации.

**Технически:**

6. Проверить 301-редиректы уровня nginx: `http→https`,
   `www.xn--j1ahceql.xn--p1ai` → голый домен (единственный хозяин домена
   в canonical/sitemap). При необходимости — добавить правила на VPS.
7. Наблюдение индексации (Вебмастер → Индексирование/Обход): ожидать
   индексацию 8 информационных URL; при появлении в обходе мусорных
   `/catalog?…`-вариантов — добавить `Clean-param` (sort, page, minPrice,
   maxPrice, available, photo, q, excludeId, storeId для /catalog и
   /product).
8. Проверить микроразметку в валидаторе Яндекса (Organization, Store ×30,
   BreadcrumbList) — поправить по замечаниям валидатора.
9. Полевые CWV: Вебмастер → «Скорость»; Метрика → «Время загрузки»;
   контролировать `/about` (лабораторно worst-case 2,57 с LCP).

## 60 дней

10. **Ревью индексации витрины (юрист + владелец)** — решение по
    `/catalog`, `/product/*`: текущее состояние noindex соответствует
    docs/COMPLIANCE.md; при положительном решении потребуется:
    - стратегия отдачи контента каталога роботам (сейчас гейт скрывает
      его в SSR) с сохранением юридических требований 15-ФЗ/38-ФЗ;
    - переработка sitemap (порциями, lastmod из `stockUpdatedAt`/цены);
    - карта slug-истории (301 при переименованиях в МойСклад — см. п. 13);
    - нейтральные заголовки категорий без рекламной семантики.
11. **Устойчивость товарных URL**: реализовать журнал переименований
    (старый slug → новый) при синхронизации с МойСклад и 301-редирект
    со старых адресов (сейчас переименование = смена URL без редиректа;
    карточки noindex, поэтому SEO-риска нет — станет актуально после п. 10).
12. `Clean-param` (если не сделано в п. 7) и Sitemap-пинг из CI после
    деплоя (упоминание `sitemap.xml` в robots уже есть).
13. Ленивая загрузка изображений товаров: `loading="lazy"` ниже первой
    строки сетки (проверить CLS — размеры уже в разметке).
14. Рассмотреть `fetchpriority`/preload для шрифта Golos Text на
    информационных страницах (LCP-текстовые страницы).

## 90 дней

15. Информационный контент (юридически безопасный): страницы
    «О компании», «Реквизиты», возможно FAQ для точек (режим, парковка)
    — без товарной/рекламной семантики; расширение sitemap по мере
    добавления.
16. Локальное присутствие: карточки организаций в Яндекс Бизнесе для 30
    точек (NAP = данные сайта; ссылки на `/stores`), согласование с
    владельцем (учёт требований к рекламе для регулируемой категории —
    только справочные данные).
17. Автоматический SEO-регресс в CI: добавить прогон `tests/seo.spec.ts`
    в GitHub Actions против preview-сборки (сейчас e2e локальные; CI
    гоняет format/lint/types/unit/build).
18. Мониторинг доступности: внешние проверки 200/404 ключевых URL
    (UptimeRobot или аналог из РФ) + алерт при падении SSL.

## Постоянный технический мониторинг

- **Еженедельно**: Вебмастер (обход, ошибки индексации, новые 4xx),
  Метрика (визиты/отказы, работоспособность счётчика — «Проверка
  счётчика», цели).
- **При каждом деплое**: CI-батарея зелёная; SEO-инварианты в
  `tests/seo.spec.ts` + `tests/legal.spec.ts` — расширять при добавлении
  маршрутов (новые страницы обязаны явно объявлять robots-статус через
  `usePageSeo({index})` — дефолт noindex).
- **При изменении данных магазинов** (адрес/часы/точки): синхронно
  обновляются JSON-LD (Store) и список `/stores` — единый источник
  `shared/content/stores.ts` + МойСклад.
- **Правовой календарь**: 01.03.2027 — лицензии 186-ФЗ (торговля без
  лицензии запрещена) и региональный запрет ЭСДН/жидкостей в Саратовской
  области (автоскрытие уже реализовано в
  `shared/legal/regional-restrictions.ts`); отражать статус на
  `/information` при изменениях.
- **Раз в квартал**: повторный технический аудит (robots/sitemap/
  canonical/404/CWV) по чек-листу SEO_AUDIT.md; актуализация
  docs/COMPLIANCE.md.
