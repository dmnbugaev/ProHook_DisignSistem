## Что изменилось в вёрстке этим аудитом

1. `.hero--floating` — `overflow-x: clip` (глушит вылет burst-анимации; в
   steady-state невидим, сцена остаётся `overflow: visible`).
2. `.promos__segment` — реальный бокс 44px, видимая полоса 6px через
   `::after { inset: 19px 0 }`, fill с собственным `border-radius`;
   на ≤767px индикатор на отдельной строке (`flex-wrap: wrap`, `order: 5`).
3. `.catalog-back` — `min-height: 44px`, `margin-block: -8px 8px`.
4. Аудит-хелпер touch-таргетов переведён на `offsetWidth/offsetHeight`
   (layout-размеры): `transform: scale(0.87)` соседних карточек карусели
   больше не даёт ложных 38px.

## Инварианты, проверенные инструментально (чисто)

- Горизонтальный overflow: свип 280–2560 × 4 движка (audit overflow-sweep) + fit-тест 375/768/1440 × 6 страниц.
- CLS = 0 на всех ключевых страницах (PerformanceObserver, layout-shift без hadRecentInput).
- Наложения интерактивных элементов: не найдено (пары ссылок/кнопок с пересечением >6×6px — 0).
- Битые изображения: 0.
- Alt-тексты: контентные изображения с alt; декоративные — `alt=""` рядом с текстом (best practice).
- Обрезка текста (text-clip): аудит-сьют зелёный.
- Мелкий текст: только caption-токен 11px (категория карточки, наличие, бейдж промо, подпись статистики hero) — применён последовательно по всей системе, является дизайн-решением; ссылка копирайта Яндекс.Карт — контент виджета, не наш.
