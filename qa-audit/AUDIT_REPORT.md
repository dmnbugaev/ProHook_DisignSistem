## Что проверено без находок

- **SEO-мета** (15 маршрутов): title/description уникальны и по длине в норме; `noindex` по доктрине (каталог/товар/поиск/логин/регистрация), контентные страницы `index, follow`; canonical (punycode) только на индексируемых; OG title+image везде; H1 ровно один на индексируемых.
- **404**: неизвестная категория/товар/страница → настоящий HTTP 404 с фирменной страницей.
- **Security-заголовки**: CSP, `X-Frame-Options: DENY`, `nosniff`, `referrer-policy: strict-origin-when-cross-origin`, `permissions-policy`, HSTS.
- **Производительность (лабораторно, localhost)**: CLS = 0 на всех ключевых страницах; LCP-элемент — текст (не заблокирован шрифтами/картинками); JS ~364–409KB (41–46 файлов); ~52–58 запросов, ~560–620KB. Абсолютные значения на localhost не показательны — реальные метрики снимать на проде (Метрика).
- **Поиск**: подсказки с устойчивостью к опечаткам («блкнот» → «Блокнот…»), Enter → `/search?q=…` с URL-кодированием, H1 отражает запрос.
- **Гейт 18+**: SSR не отдаёт регулируемый контент; возрастная строка на всех страницах; модаль только на закрытых маршрутах.

Детали воспроизведения и инструменты: `qa-audit/tools/` (find-overflow, diag-*, verify-*, seo-meta-sweep, perf-probe, screenshot-sweep).
