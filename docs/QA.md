# Проверка сайта-каталога

## Интеграция МойСклад — 27 сентября 2026

Каталог подключён к JSON API 1.2 МойСклад. Первая полная синхронизация сохранила 5 790 товаров с положительной ценой, 272 используемые категории и 30 торговых точек. Проверен отчёт остатков, цены «Цена продажи» и «Москва», локальный API и серверная выдача PNG-фотографии. Ключ находится только в игнорируемом Git файле `.env`; в production-сборке токен не найден.

После обновления тестов 34 браузерные проверки прошли в Chromium и WebKit на отдельном тестовом снимке. Два модульных теста проверяют поле публикации, цены по городам и остатки. Пройдены `lint`, `format:check`, `typecheck` и production-сборка. Исторические скриншоты и результаты ниже относятся к прежнему демонстрационному набору данных.

27 сентября 2026 года. Реализованы и проверены главная, каталог, категории, товар, поиск и информационные страницы. Вымышленные нейтральные данные; внешняя публикация не выполнялась.

| Проверка | Результат |

| npm run lint | Успешно, 0 предупреждений |
| npm run format:check | Успешно |
| npm run typecheck | Успешно |

Команда полного production-прогона: `PLAYWRIGHT_BASE_URL=http://127.0.0.1:4317 npm test` после `npm run build`.

Покрыты: возраст 18+, обязательный первоначальный выбор города и магазина, сохранение выбора в cookie, отсутствие повторного AgeGate при клиентской навигации, цены и статусы по точкам, фильтры и диапазон цен, сортировка, query params, back/forward, пагинация, подкатегории, поиск, пустая выдача, галерея, отсутствие изображения, HTTP 404, ошибка API и повторная загрузка, skeleton, клавиатура и мобильный drawer. Старые сценарии дизайн-системы также проходят.

Во время проверки обнаружено, что порт 3001 уже занят существующим dev-сервером. Первоначальная конфигурация Playwright повторно использовала его, поэтому попытки production-прогона фактически работали с dev-сервером и иногда фиксировали отменённый служебный запрос dev.json в WebKit. Для production теперь запрещено повторное использование существующего сервера; итоговый прогон запускает свежую production-сборку на отдельном порту 4317. Тест переходов также ждёт окончания сетевой загрузки перед следующей навигацией. При изолированном запуске исправлена исходная команда preview: Nuxt CLI не поддерживает --host для preview; локальный адрес теперь задаётся через NITRO_HOST.

При визуальной проверке исправлена нативная высота select в WebKit: 25 px при заданном минимуме 48 px. Для общего поля выбора задан appearance:none и сохранён чёрный индикатор раскрытия; тест контролирует минимальный размер нажатия. Также исправлены ложное активное состояние ссылки «следующая страница», склеивание текста при скрытии br на mobile и перекрытие существующей стеклянной подложки Header непрозрачным фоном. В Chromium при полноразмерном скриншоте после прокрутки/смены viewport наблюдались артефакты отрисовки фиксированной панели. Итоговые полноразмерные снимки пересохранены в WebKit в новом контексте для каждого viewport.

Снимки: `screenshots/catalog/{home,catalog,product}-{375,768,1440,1920}.png`, `mobile-filters.png`, `mobile-menu.png`, `store-picker.png`. Шрифты и изображения загружены перед съёмкой; reduced motion включён. В отдельном проходе Chromium не зарегистрировал console warnings/errors.

Проверка выполнялась на настольных браузерных движках с заданными viewport. Физические телефоны и скринридеры не проверялись. Реальные API, юридические документы, контакты и товарные фотографии остаются за пределами демонстрационных данных.

Итоговый снимок 768 px проверен визуально.

# Предыдущая проверка исходной дизайн-системы

## Результаты

## Покрытие

- Диалог: начальный фокус, полный цикл Tab и Shift+Tab, блокировка фоновой страницы и прокрутки, Escape, возврат к инициатору, повторное открытие и закрытие кнопкой.
- Мобильное меню: клавиатура, возврат фокуса, переход по якорю и снятие блокировки прокрутки.
- Вкладки: стрелки, Home/End, активная панель и ARIA-связи.
- Поля: невалидный email, доступное описание ошибки, исправление и локальная проверка, живой предпросмотр.
- Header: переход к стеклу, сохранение высоты, гистерезис 40/16 px.
- Движение: обратимость при прокрутке, статичный переключатель, системный reduced motion.
- Без JavaScript: текст и завершённая декоративная композиция остаются доступны.
- Ширины: 320, 375, 390, 768, 1024, 1440, 1920 px; альбомное окно 844 × 390. Горизонтального переполнения страницы нет, изображения загружаются.
- Увеличение текста: фактические размеры шрифтов умножены на 2 на ширинах 320, 390, 768, 1024 и 1440 px; переполнения страницы нет.

## Визуальная проверка

Через agent-browser проверены первый экран desktop/mobile, меню, раздел компонентов и общая композиция страницы. Скриншоты доступны в `screenshots/`: `desktop.png`, `mobile.png`, полные версии `desktop-full.png` и `mobile-full.png`, `mobile-components.png`, `text-200-mobile.png`.

Перед полноразмерными скриншотами загружены изображения с lazy loading; при обычном просмотре они загружаются по мере приближения к viewport.

Автоматический аудит оставил пять узлов на ручную проверку контраста: два декоративных символа палитры и три текстовых элемента поверх фоновой сетки. Символы чёрные на белом и белые на чёрном, скрыты от скринридера. Текст в образце использует #000000 / #595959 поверх белой поверхности с тонкой сеткой чёрного цвета с непрозрачностью около 2%; контраст достаточен. Аудит не заменяет тестирование со скринридером.

## Исправлено во время проверки

- Полный цикл фокуса внутри dialog вместо зависимости от поведения браузера и системных настроек Safari.
- Фокус инициатора при клике в WebKit, где кнопка не всегда получает его автоматически.
- Переносы при увеличении текста до 200%: Header, палитра, образец «Аа», ссылки и кнопки.
- Скрытие skip-link независимо от высоты его текста.
- Пробелы возле переносов строк, которые скрываются на мобильном экране.
- Тесты ждут гидратацию Nuxt перед действиями; тест обратимости ждёт первый рассчитанный кадр анимации.

## Границы проверки

Проверены браузерные движки Chromium и WebKit на настольной машине с изменением viewport. Физические телефоны и скринридеры не использовались. Анимации и мобильные версии внешних сайтов-референсов визуально не проверялись; точное совпадение с ними не заявляется. Официальный векторный логотип и брендбук не предоставлены.
