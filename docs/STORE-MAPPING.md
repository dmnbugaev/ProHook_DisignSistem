# Сопоставление магазинов с МойСклад

Проверка API `entity/store` от 4 октября 2026 года: 43 склада, 30 неархивных торговых точек (27 в группе «Саратов», 3 в группе «Москва»). В запросе заказчика — 30 адресов. Совпадение количества само по себе не подтверждает соответствие адресов.

Сняты ручные исключения для «Вокзала», «Буровой», «Ильинской площади» и «Чапаева 45». Последнего имени сейчас нет в API. Служебные и архивные склады по-прежнему не публикуются. Учётные названия и данные в МойСклад не изменялись.

29 подтверждённых соответствия адресов хранятся по стабильному ID склада в `server/data/store-addresses.ts`. В их числе «Буровая» → ул. Буровая, 25 и все три московских магазина. Их московские адреса дополнены из названий складов API. Остатки присоединяются по ID, а не по отображаемому названию.

## Часы работы точек

Общий режим сети — `shared/content/prohook.ts` («Ежедневно, 9:00–22:00»,
изменено 10.10.2026). Индивидуальные часы — `server/data/store-hours.ts`
по стабильному ID склада (правки владельца со скриншота 10.10.2026):
«Вокзал» — 9:00–22:00, «Крымская, 9» — 9:00–21:00. Точка без записи
показывает общий режим сети.

После подтверждения измените `store-addresses.ts`, выполните `npm run catalog:sync` и перезапустите сервер, если он уже держит старый снимок в памяти. Изменения исходников требуют новой production-сборки.

## Результат проверки

Полная синхронизация 4 октября 2026: 5 916 товаров, 281 категория, 30 магазинов. Для каждого магазина в свежем отчёте есть товары в наличии. Адреса заполнены для 29 точек; «Мичурина 51» ожидает уточнения.

Проверены production-сборка, lint, TypeScript и модульные тесты. Локальная HTTP-проверка собранного сайта: `/api/catalog/meta` возвращает 30 точек; `/api/products?storeId=…&available=1` возвращает непустую выдачу для каждой точки; `/stores` содержит подтверждённые адреса и больше не показывает старое сообщение о закрытии.

## Публичный список точек для карты (октябрь 2026)

Блок «Наши магазины» на `/contacts` использует независимый публичный конфиг
`shared/content/stores.ts` (30 точек: 27 Саратов + 3 Москва), а не учётный
`server/data/store-addresses.ts`. Адреса двух источников должны совпадать —
это проверяет юнит-тест `tests/stores-data.test.mjs` (`npm run test:unit`).

Координаты лежат в `shared/content/store-coordinates.json` и заполняются
скриптом `npm run stores:geocode` (только российские сервисы: Яндекс —
`YANDEX_GEOCODER_API_KEY`, 2ГИС — `TWOGIS_CATALOG_API_KEY`) либо вносятся
вручную. Карта на `/contacts` — JS API Яндекс.Карт, работает без ключа.

российские сервисы»; 3 недостающие точки дополнены вручную с публичной
